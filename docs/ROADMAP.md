# Delivery milestones and acceptance criteria

The source repository is not proof of a passing build or production readiness.

## M1 — foundation (10%)
- [x] Next.js application scaffold
- [x] Site schema and starter themes
- [x] Read-only integration capability endpoint

## M2 — builder basics (25%)
- [x] Editor, sections, preview, HTML export
- [x] Local project storage and JSON import/export
- [x] Interactive WebGL scene preview

## M3 — composition (40%)
- [x] Experimental block composer
- [ ] Persistent page composer integrated with main site projects
- [ ] Full block layout and responsive styling

## M4 — platform (60%)
- [ ] Authenticated tenant-specific project persistence
- [ ] Asset management and upload validation
- [ ] Revisions and rollback
- [ ] Database migrations and recovery tests

## M5 — intelligence (75%)
- [x] Optional AI provider adapter and schema validation
- [ ] Authenticated quotas and durable rate limiting
- [ ] Prompt-to-layout generation, not only copy
- [ ] Audited Growth Lens and LeadFlow connectors

## M6 — publish and quality (90%)
- [ ] Passing typecheck, production build and integration tests
- [ ] Publish, preview URLs, rollback and custom domain path
- [ ] Accessibility and performance testing
- [ ] Security hardening and monitoring

## M7 — general availability (100%)
- [ ] Load testing, operational runbooks, backups and recovery rehearsal
- [ ] Production deployment and monitoring

Percentages above are acceptance checkpoints, not claims of achieved completion.
